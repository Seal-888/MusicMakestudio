# PLI Music Studio

내 맥에서만 도는 버전. 서버도 로그인도 없고, 브라우저가 API를 직접 부릅니다.

## 시작하기

1. 이 폴더를 원하는 곳에 둡니다.
2. `run.command`를 더블클릭하세요. 터미널이 열리고 브라우저가 뜹니다.
3. 처음이라면 **API 설정**에서 키를 넣고 **테스트**를 눌러 초록불을 확인하세요.

`run.command`가 안 열리면 터미널에서 한 번만:

```bash
cd <이 폴더 경로>
chmod +x run.command
xattr -d com.apple.quarantine run.command
```

두 번째 줄이 꼭 필요합니다. 인터넷이나 압축 파일에서 받은 파일에는 macOS가
격리(quarantine) 표시를 붙이는데, 실행 권한만 줘서는 이게 안 풀립니다.
`xattr`가 "그런 속성 없음" 오류를 내면 이미 풀린 것이니 넘어가면 됩니다.

이래도 "확인되지 않은 개발자" 경고가 뜨면 파일 우클릭 → **열기**를 고르세요.

## 왜 파일을 그냥 열면 안 되나요

`file://`로 열면 ES 모듈을 불러오지 못합니다. 꼭 `run.command`로 여세요.

## 브라우저

**Chrome 또는 Edge**를 권합니다.

## 키는 어디에 저장되나요

이 브라우저의 localStorage에만 저장됩니다. 어디로도 전송되지 않고, 이 폴더 안에도 기록되지 않습니다.
대신 **브라우저 데이터를 지우면 같이 사라집니다.** API 설정 맨 아래 "파일로 내보내기"로 가끔 백업해 두세요.

**백업 파일에는 API 키가 그대로 들어 있습니다.** 이 저장소는 공개이므로 백업 파일은 앱 폴더 밖(다운로드 폴더 등)에 두세요.
실수로 넣어도 올라가지 않게 두 겹으로 막아 두었습니다.

- `.gitignore` — `plimusic-backup*.json` 같은 백업 파일 이름은 `git add` 에서 빠집니다.
- `.githooks/pre-commit` — 이름을 바꿨거나 `git add -f` 로 넣어도, 커밋할 내용에 API 키(`AIza…`)가 보이면 커밋을 멈춥니다.
  `npm install` 을 한 번 하면 자동으로 켜집니다. (`npm install` 없이 켜려면 `git config core.hooksPath .githooks`)

## 고치기 전에 검사부터

의존성을 한 번만 받아 두면 됩니다.

```bash
cd <이 폴더 경로>
npm install
npm test
```

13종이 모두 통과하면 안전한 상태입니다. 화면이 열리는지, 버튼이 실제로 동작하는지,
저장이 조용히 실패하지 않는지까지 브라우저 없이 확인합니다.
코드를 고친 뒤에는 항상 한 번 돌려 보세요.

## 폴더 구조

```
index.html          화면 뼈대와 사이드바
css/style.css       전체 스타일
js/app.js           페이지 전환
js/store.js         localStorage (키, 보관함)
js/ui.js            알림 같은 공용 조각
js/api/             Gemini · YouTube 호출
js/videostats.js    유튜브 영상 통계 (하루 평균 조회수 · 쇼츠 구분) — 분석 화면들이 같이 씀
js/audio.js         곡 길이 재기
js/lyrics.js        가사 규칙 검사 · 자막 줄 맞추기
js/prompts.js       Gemini 프롬프트 ← 결과가 마음에 안 들면 여기를 고치세요
js/render.js        결과 화면 공용 조각
js/version.js       bump.mjs가 만드는 버전 표시 (직접 고치지 않음)
js/pages/           화면별 코드
js/mastering/       마스터링 엔진 (engine.js 계산 · worker.js 백그라운드 실행 · wav.js 내보내기)
docs/               캡컷 draft 포맷 해독 문서 (기능은 제거됨, 참고용)
serve.py            로컬 정적 서버 (localhost 요청만 받음)
bump.mjs            git 커밋 수로 버전 갱신
check-*.mjs         브라우저 없이 도는 검사들 (npm test)
```

바꿀 일이 가장 많은 곳은 `js/prompts.js`입니다. 결과물 품질은 거의 다 거기서 결정됩니다.
